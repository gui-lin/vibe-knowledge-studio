# 选题、文案与发布

## 选题公式

一个好题 = **硬知识 + 私人相关 + 一个年份 + 一个数字 + 一句金句**

| 要素 | 说明 | 例 |
|---|---|---|
| 硬知识 | 有名字的理论/实验/定律/史实 | 秘书问题、布雷斯悖论、超常刺激、唐代烽燧制度 |
| 私人相关 | 大理论必须落到"你"身上 | 相亲、堵车、奶茶戒不掉、落榜裁员 |
| 一个年份 | 历史感 = 可信度 = 大片感 | 1494 / 1611 / 1944 / 1962 |
| 一个数字 | 反直觉、可复述的记忆锚 | 37%、23 人、253 对、15:1 |
| 一句金句 | ≤16 字，可单独转发 | "断掉的，是一条路，不是你的人生" |

转发率最高的是"硬知识 + 人生/情绪"；国学、历史、游戏原理都已验证能爆。蹭节点：诺奖季、高考、开学、节气。

**自检**：用一句话说出"看完这条，观众会对朋友复述哪一句？"说不出来就换题。

## 六段式（按 130s 计；120–180s 等比放缩）

| 段 | 时长 | 功能 | 写法 |
|---|---|---|---|
| ① 冷开场钩子 | 0–8s | 让观众先"遇到"概念 | 2–3 句极短字幕；句式：A，却 B？/ 你以为……/ 如果 X，你会 Y 吗？ |
| 片名卡 | 8–20s 之间 | 悬念 → 命名 | `titleAt` 对上配乐满编进入；片名卡 4–6 秒，无字幕 |
| ② 历史锚点 | ~17% | 年份 + 地点 + 人物 + 文献 | 顶标签"1950 · WASHINGTON"；文献复原卡 + 印章 + 「图为示意」 |
| ③ 机制演示 | ~45% | 核心：一步一步演 | 先立规则卡，再推演；每步一个动作 + 一句字幕；图要真算 |
| ④ 反直觉转折 | ~12% | 记忆点 | "还有一个反直觉的细节"；前面结论翻转、并排对比；**静音放在这里** |
| ⑤ 现实落点 | ~12% | 拉回今天和"你" | 诺奖/现实系统/生活映射；给一句可转发的金句 |
| ⑥ 收尾 | ~8% | 可信 + 互动 | 回扣开场画面 → 免责声明 → 参考文献 → 一个开放问题 |

## 字幕写法

- 一句 ≤ 20 字，一屏一句；停留 ≥ 每字 0.14 秒（约 3 秒一句；带英文的 4–5 秒）
- 字幕覆盖全片 58–74% 的时间，其余留给片名、转场和纯画面
- `[关键词]` 染金、`{负面词}` 染红；全片金色关键词不超过 10 处，多了就不亮了
- 英文副行：意译，不要逐字翻；短于中文
- 不说"今天我们来讲"；不用感叹号堆情绪；结论句用短句
- 每一句都要能在画面里找到对应的动作，没有动作认领的字幕删掉

## 事实核查清单

| 项 | 要求 |
|---|---|
| 年份、人名、地点 | 至少一个可靠出处（论文、教科书、百科条目的原始引用） |
| 论文/书名 | 用原题（外文原题 + 中文译名，译名注明"意译"） |
| 数据 | 写清样本、年份；计算类的自己在 film.js 里算一遍 |
| 引语 | 找到原文；找不到就写"据说"或删掉 |
| 前沿结论 | 查最新研究是否推翻（例：雷电起电机制有新研究） |
| 历史图像 | 一律标「图为示意」 |
| 敏感建议 | 恋爱、医疗、投资类加免责声明卡 |

## 发布文案（抖音）

- **标题**：`Vibe知识大赏｜《片名》一句钩子？`
- **正文**：2–3 句，必含一个具体年份 + 人名 + 反直觉结论；结尾抛一个问题（"你曾经以为断掉的那条路，后来把你带去了哪里？"）
- **话题**：`#vibe知识大赏` + 3–5 个主题词（#概率论 #心理学 #历史冷知识 …）
- **作者声明**：勾选"内容由 AI 生成"
- **评论区置顶**：参考文献 + "本片画面与声音由代码生成，无实拍素材"
- **封面**：`out/cover.jpg`（默认取片名卡后 2 秒），可用 `meta.cover` 指定时刻
