# 画面规范

## 三套世界（`meta.world`）

| | `night` 夜曲 | `gilt` 鎏金暗场 | `paper` 宣纸水墨 |
|---|---|---|---|
| 适合 | 抽象概念：数学、信息、逻辑、物理 | 一门学问的编年史：一串"年份 + 人 + 问题" | 国学、历史、人生道理；竖屏尤其合适 |
| 原片 | 《信息论》《自指》 | 《运气的形状》《超常刺激》 | 《道家》 |
| 底 | 引擎默认：蓝黑夜空 + 细星点，中央一团深蓝（**太蓝，见下方「电影质感」**） | 近黑暖棕 + 上方光池 + 漂浮的失焦尘埃，四角压暗 | 米白宣纸纹理 + 纤维 + 边缘泛黄 |
| 颜色 | ink 白、gold 金（惊奇/真）、ice 冰蓝（已知/可证）、rose 玫红（错/噪声） | ink 象牙白、gold 金、rose 朱红、ice 冷蓝 | ink 墨、rose 朱砂印、gold 赭金 |
| 片名 | 细宋金字 + 辉光 | 粗宋金字 | 粗宋墨字 |

**颜色是语义，不是装饰**：观众不读字也能从颜色知道结论方向。全片金色像素实测 ≤ 7%，单屏峰值在"数字钩子"那一屏。
要换配色就在 film.js 里写 `colors: { gold: '#…' }` 覆盖，别改语义。

## 电影质感（夜曲世界）

实测对比见 `research.md`：《信息论》接近纯黑，亮度中位 8.8，有全屏大事件；《生日悖论》发蓝、亮度 13.3，画面变化最大只有 19.9%，看起来像 PPT 和数据看板。

| 项 | 要求 | 现在怎么做 |
|---|---|---|
| 底色 | 接近纯黑，不要看得出的蓝色渐变和满屏均匀星点 | `colors: { bg: '#000000', core: '#000000', stars: false }`；需要星空的段落在场景里单独画 |
| 光晕 | 亮元素带柔和外发光 | 组件的 `glow`；更强的效果在 film.js 写局部函数 |
| 横向光条 | 亮点带细长的水平镜头光条 | film.js 局部函数（引擎未内置） |
| 颗粒 | 全片一层很淡的细颗粒，压住数字感 | film.js 局部函数（引擎未内置） |
| 粒子文字 | 片名和关键句由粒子聚成、散开 | film.js 局部函数：读文字像素转粒子（引擎未内置） |
| 全屏大事件 | 全片 1–2 次，整个画面换世界（噪点铺满、宇宙展开、光点炸开），放在揭晓处 | 场景里画；出片后看关键帧，确认真的铺满了全屏 |
| 不用看板 | 能用场景讲的不要用坐标图：山河烽火比折线图好。必须出图时让它是场景的一部分，不要一直停在图表上 | `c.curve` 只留给公式本身就是答案的时刻 |

**局部函数的成本**：2D Canvas 逐帧做光晕和粒子会明显拖慢渲染。想要《第一秒》那种质感，目前只能另写 three.js（参考 `film/film.js`）；引擎还不支持。

## 版式（16:9；竖屏按比例上移）

```
中央  主动画区：屏上大字和画面是主角
~70%  画面注释小字（解释当前动画，少用）
~86%  中文字幕（46px）+ 下方英文斜体（约 26px、灰）        竖屏在 ~79%，54px
```

- **默认不要常驻界面**：`meta.author` 和 `chapters` 都不写，就没有左上水印和右上章节标。它们会把片子变成课件
- 一屏一个主角；字幕和画面不抢同一块地方
- 数字（年份、概率、百分比）要大：它们是节奏锚点
- 竖屏：主角放上半，字幕在 79%；横向留够安全边（左右各 6%）

## 动效规则

| 规则 | 做法 |
|---|---|
| 先演，后命名 | 片名放在观众第一次尝到甜头之后：不用热门 BGM 时通常 20–40s（《信息论》27–38s），用热门 BGM 时约 17s |
| 母题贯穿 | 一个元素穿过所有世界：《信息论》的光点走过山河、城市和太空，最后连成链。世界可以换，母题不换 |
| 一句字幕一个动作 | 字幕说"摸两万五千次"，计数器就真的数到 25,000 |
| 图是算出来的 | 模拟用 `rng(seed)` 真跑；挑一个让节奏最好的种子（示例里自动搜索） |
| 缓动 | 全用 `ease.io` / `ease.out` / `ease.back`，不要匀速 |
| 进场 | 淡入 + 上移 8–10px；纸卡带轻微旋转落定；线条逐段画出（`c.path` 的 `p`） |
| 强调 | 变金 + 辉光；数字快速滚动 |
| 转场 | 内容长出来：卡片飞散重组、曲线延伸成地平线、格子放大成地图。几乎不硬切、不黑场 |
| 闪亮 | `c.flash(t)` 只用在章节开头和定理落地，全片 3–5 次 |
| 留白 | 字幕出完留 1–2 秒给人读；但不能整段死帧：静止超过 4 秒就加缓慢推近、漂移、星点、进度点（体检会查） |
| 回扣 | 结尾回到开场画面和开场那句话，意思变了；不要停在参考文献页 |

## 母题库（对应组件）

| 母题 | 组件 | 用在哪 |
|---|---|---|
| 文献复原卡（真实标题 + 做旧纸 + 印章 + 示意） | `c.doc` | 历史锚点，几乎每条都有 |
| 规则卡（①②③ 逐条出现 + 英文） | `c.rules` | 机制演示前先立规则 |
| 带彗尾的光点沿线跑 | `c.comet` | 夜曲世界的主角 |
| 函数曲线逐段生长 + 坐标轴 | `c.curve` + `c.axes` | 最优解、收敛、分布 |
| 计数器 | `c.num` | 模拟次数、概率、年份 |
| 点阵 / 网格（一格一个样本） | `c.box` 循环 | 万次模拟 |
| 环、刻度、日历 | `c.path` 循环 | 时间、周期 |
| 打字机 + 光标 | `c.type` | 填空题、"床前明月＿" |
| 印章 | `c.seal` | 文献、规则卡、结论盖章 |
| 扩散圆环 | `c.ring` | 碰撞、命中、落点 |

更复杂的（人物剪影、地图、粒子）直接在场景里用 `c.x`（CanvasRenderingContext2D）画，画法见示例。
