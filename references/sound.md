# 声音规范

## 铁律

- **没有人声**。旁白就是字幕；音轨是连续的音乐底 + 事件音
- 响度要有起伏，不要又平又满。合成配乐默认设 `meta.loudness: -18`；用热门 BGM 的片子才跟 -14。峰值 -1.5 dBTP
- 不打包别人的曲子。外部曲必须有授权，用 `meta.music.file` 引用

### 动态目标

《信息论》RMS 约 -19 dB，每 5 秒响度在 -14 到 -26.9 之间，约 13 dB 起伏；《生日悖论》按 -14 LUFS 出片，约 6 dB，又平又满。
目标：每 5 秒响度范围 ≥ 10 dB（经验值，待更多片子验证）。引擎不查这一项，出片后自己量：

```bash
ffmpeg -i out/片名.mp4 -af "asetnsamples=n=220500,astats=metadata=1:reset=1,ametadata=print:key=lavfi.astats.Overall.RMS_level:file=-" -f null - 2>/dev/null | grep RMS_level
```

（`n=220500` 按 44.1 kHz 算，采样率不同就改成 5 × 采样率；片尾不足 5 秒的段和接近 -100 的数字静音不算。）引擎的 `loudnorm` 是单遍处理，可能压掉一部分动态，所以要量成片，不要只看 sections 怎么写。

## 两条路线

| | 代码合成（默认） | 外部授权曲 |
|---|---|---|
| 写法 | `music: { bpm, key, sections }` | `music: { file: 'bgm.mp3', gain: -8, offset: 0 }` |
| 原片 | 《信息论》用作者原声（-19 dB，很安静；具体怎么做的不清楚） | 话题里半数头部视频用同一首氛围钢琴曲（~112 BPM） |
| 好处 | 每个拍点都能对画面；不撞款 | 熟悉感红利 |
| 代价 | 要设计段落 | 同质化，评论区会说"又是这首" |

### 合成配乐的段落

`sections: [[时刻, 织体], ...]`，从该小节起生效：

| 织体 | 内容 | 放在 |
|---|---|---|
| `pad` | 只有长音铺底 | 冷开场钩子 |
| `full` | 琶音 + 低音 + 轻打击；**进入那一拍自动加一记低鼓 + 闪光音** | 第一次揭晓或片名（设成小节起点：76 BPM 一小节 3.158s） |
| `piano` | 柱式和弦 | 历史锚点、现实落点 |
| `arp` | full + 高音琶音 | 机制演示高潮段 |
| `rest` | 什么都没有 | 静音段前后 |
| `outro` | 单音钢琴 | 收尾卡 |

调式 `key`：Am / Bm / Cm / Dm / Em / Fm / Gm（小调 i–VI–III–VII 循环）。

### 外部曲对齐

```bash
node engine/beats.mjs 曲子.mp3
```
打印 BPM 和"段落进入"重音点。实测热门那首重音在 17.1s 和 93.6s，用这首曲子的爆款片名卡落在 17s 附近。
这条只适用于外部曲：把 `titleAt` 和章节转折对到这首曲子的重音上。合成配乐反过来，让配乐跟着揭晓走。

## 事件音（`c.sfx(t, 名字, 参数)`）

在画面代码里就地记，跟动作绑在一起不会错位。同一个（时刻，名字）只记一次。

| 名字 | 声音 | 默认增益 | 用在 |
|---|---|---|---|
| `tick` | 短玻璃嗒（`pitch` 变音高） | -24 dB | 打字、计数、小元素出现（`c.type` 自动加） |
| `soft` | 柔和玻璃触音 | -18 | 点落下、标签淡入 |
| `chord` | 带泛音的钟声和弦，8 秒衰减（`root` 半音偏移） | -12 | 章节开头 |
| `bloom` | 和弦 + 一口气 | -10 | 片名卡、闪亮（`c.flash` 默认） |
| `rise` | 上滑音（`dur`） | -16 | 揭晓前、提问处 |
| `thud` | 低频闷击 | -8 | **全片 ≤ 3 次**的重音 |
| `boom` | thud + shimmer | -6 | 碰撞、定理落地 |
| `stamp` | 印章声 | -12 | 盖章、文献落定 |
| `shimmer` | 高频碎光 | -18 | 模拟开始、星点 |
| `whoosh` | 气流（`dur`） | -18 | 转场、连线铺开 |
| `hush` | **之后彻底静音 `dur` 秒** | — | 见下 |

避开：epic、trailer、explosion、cartoon、ding——这套风格的事件音要"闷、短、不抢戏"。

## 三个最有效的技巧

1. **重音跟着揭晓走**：《信息论》的瞬态落在 0.1、24、64.1（揭晓 693）、97.6、169.3、204.4（全屏噪点）、262、291.5 秒，大多是观众得到答案或画面变世界的时刻，不是段落交接。
   分镜表先标揭晓时刻，再放 `thud`/`boom`（全片 ≤ 3 次；瞬态可以更多，用 `bloom`、`chord` 这类轻一些的音）。
2. **静音要和内容有关，全片一次**：完全静音 2–3 秒，答案随声音一起回来。
   最好的用法是静音本身就在演这句话：《信息论》问「噪声越大，会不会吞掉一切」时，声音真的消失 2.4 秒（166.9–169.3s），答案处响度跳升。
   没有这样的句子，就放在高潮之后、结论之前。
   写法：`c.sfx(t, 'hush', { dur: 2.5 })`，配乐 sections 同时设成 `rest`，揭晓那一刻 `c.flash`。
3. **声音即内容**：讲噪声时音轨真的变吵；讲期待/延迟满足时真的多等一小节；讲节拍时真的出节拍。
   观众"亲身体验"了概念，这是评论区说"想落泪"的那种片子的共同点。

声音是《信息论》被讨论最多的部分之一，前 30 条评论多处提到它。配乐不要留到最后再补，分镜阶段就设计。
